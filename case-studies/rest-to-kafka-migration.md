# Zero-Downtime Migration: Synchronous REST → Kafka Event Pipelines

**Role:** Engineering Manager (Senior Development Lead) · Girmiti Software · 2021–2026
**Domain:** Platform Architecture / Distributed Systems

## Context

Core services were built on synchronous REST calls, creating tight coupling and scaling limits across a system operating in multiple global regions. The business needed an event-driven architecture without disrupting a live, revenue-critical platform.

## What I Did

- Led the architectural migration from synchronous REST to Kafka-based event pipelines running on Kubernetes.
- Sequenced the migration across **3 global regions** to avoid any customer-facing downtime.
- Concurrently led a live Postgres schema migration as part of the same initiative.
- Coordinated across teams to manage cutover risk, rollback plans, and regional dependencies.

## Outcome

- Completed the migration with **zero downtime** across all three regions.
- Improved system scalability and decoupling, enabling faster independent service delivery going forward.
